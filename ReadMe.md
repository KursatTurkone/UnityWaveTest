# Unity Wave Test Project

This repository contains a small **Unity 2D top-down prototype** used as a technical assessment for C# / Unity developers.

The project is intentionally simple in visuals and scope, focusing on **code quality, architecture, and problem-solving** rather than polish or content.

For more details, please refer to the assignment description in `Assets/_Project/Readme_Candidate_en.md`.

---

## Project Details

- **Engine:** Unity (2D)
- **Input System:** Old Input Manager
- **Graphics:** Basic Unity 2D shapes
- **Scene:** `Main.unity`

---

## Getting Started

### Requirements
- Unity **6000.0 LTS or newer** (recommended)
- Git

### Setup
1. Fork and Clone the repository
2. Open the project in Unity Hub
3. Load the scene:  
   `Assets/_Project/Scenes/Main.unity`
4. Press **Play**

### Submitting
1. Commit your changes to your forked repository
2. Push to your remote branch
3. Create a Pull Request to the original repository
4. Share the PR link with the evaluator

> **Note:** Your last Commit before the time limit will be considered for evaluation.
---

## Controls

- **Move:** WASD / Arrow Keys
- **Shoot:** Left Mouse Button / Ctrl (`Fire1`)
- **Restart:** `R`
- **Pause:** `Esc`
